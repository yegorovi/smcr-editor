# SMCR Editor

Настольная утилита для музыкальных кассет в моде DayZ **SM_Car_Radio**. Преобрести мод вы можете в [дискорд сервере автора}(https://discord.gg/khA6Pf6EF). Мод описывает каждую кассету в `config.cpp` — блок шейдеров, блок сетов, класс предмета, плюс две строки в stringtable. Вручную это правится долго и однообразно; редактор делает то же самое из имени кассеты и ogg-файлов.

![окно редактора](screenshot.png)

## Что умеет

- Создание и удаление кассет. При сохранении правится `config.cpp` и `stringtable.csv`, звук копируется в `Sounds\`; перед записью рядом кладутся бэкапы `.bak`.
- Длительность треков читается из ogg, названия подставляются из имён файлов.
- ogg и mp3 перетаскиваются в окно мышью.
- mp3 конвертируется в ogg прямо в программе: ни ffmpeg, ни других внешних конвертеров не нужно.
- Имена файлов при сохранении автоматически переводятся на латиницу.

Последнее — не украшение. Движок DayZ не открывает пути с кириллицей внутри PBO, такие треки в игре молчат. Редактор переименовывает файлы сам; заголовки треков и альбома остаются русскими, в путях они не участвуют.

## Работа с программой

1. Указать папку распакованного мода - ту, где лежит `config.cpp`.
2. «+ Новая кассета»: имя (латиницей), альбом, название предмета, описание, папка в `Sounds`.
3. «+ ogg…» — выбрать файлы, или просто перетащить их в окно.
4. «Сохранить в мод».

Дальше мод собирается в PBO как обычно. Скрипты мода править не нужно — реестр кассет строится из конфига.

Спавн предметов (`types.xml`) редактор не трогает: если кассета должна выпадать как предмет, пропишите её в экономике отдельно.

## Запуск

Программа portable, один exe, рядом ничего класть не нужно:

```
smcr_editor.exe
smcr_editor.exe --root="D:\path\to\SM_Car_Radio"
```

Последнюю открытую папку помнит, поэтому обычно просто запускаешь.

## Сборка

Нужны Qt 6 (Widgets) и CMake:

```bat
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:\Qt\6.9.1\mingw_64
cmake --build build
```

Под MinGW после сборки положить рядом плагины Qt (`windeployqt` по exe). Линкуется с `-static-libgcc -static-libstdc++`.

## Устройство

| файл | что внутри |
|---|---|
| `modfile.cpp/h` | разбор и запись `config.cpp`, `stringtable.csv`, копирование ogg |
| `mainwindow.cpp/h` | интерфейс |
| `ogg.cpp/h` | чтение длительности из ogg-страниц |
| `convert.cpp/h` | конвертация mp3 → ogg |
| `thirdparty/` | minimp3, libogg, libvorbis (собраны в проект статикой) |

## Третьи стороны

- minimp3 — декодер mp3, public domain.
- libogg и libvorbis — библиотеки Xiph.Org, лицензия BSD.
